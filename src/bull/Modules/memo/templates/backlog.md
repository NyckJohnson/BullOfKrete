# <App name> feature ideas

One `##` section per idea: the heading is the idea's title, and the text under it (trimmed) is its
description. Queue them all with `bull feature import <this file>`; ideas already in the backlog
are skipped. Replace the examples below with your own.

## Export orders as a spreadsheet
Let the user export the order list, with its current filters, to a file they can open in a
spreadsheet program. One row per order; the columns match the list.

## Remind the user about unpaid invoices
Show a reminder when an invoice is more than 30 days unpaid, with a way to open it or dismiss the
reminder for a week.
