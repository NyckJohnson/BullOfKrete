---
description: Show pipeline progress and plan usage
---

Run `ios-pipeline status summary` and `ios-pipeline status usage-check`
and report the result to the human in a few lines: stage, modules done/total,
the current or next step, anything blocked, and plan usage. If there is an active feature, an adoption in progress,
or a backlog, add a line for each (`ios-pipeline status feature list` has the details).
